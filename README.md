# Champion's Atlas

Find your next Pokémon Champions doubles team.

A personal-first, mobile-friendly team browser that combines Pokémon and set
filters with regulation-aware result ordering. Browse without a team in mind,
find teams around a preferred core, and keep your current teams locally.

The project is in planning. See [the product specification](docs/product-spec.md) for
agreed scope, ranking examples, data research, and implementation milestones.

Development tooling and deployment are not selected yet. Tooling choices should
follow [mw-kit](../mw-kit/README.md) where applicable.
